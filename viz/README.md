# viz/

Побудова інтерактивної карти знань.

## Призначення

Перетворити граф тем/тегів (з `analysis/`) на інтерактивну візуалізацію, зрозумілу для нетехнічної аудиторії (початківців у Data Science).

## Планована структура

- `build_graph.py` — побудова графа networkx (вузли = теми/технології, ребра = зв'язки за спільними статтями/тегами)
- `render_map.py` — рендер інтерактивної карти (pyvis або plotly)
- `app.py` — (опційно) Streamlit-застосунок для інтерактивного перегляду карти в браузері

## Принципи візуалізації

- Розмір вузла = популярність теми (кількість статей)
- Товщина ребра = сила зв'язку між темами
- Кольорове кодування — за категорією/напрямом (наприклад: ML, статистика, інструменти, MLOps)
- Інтерактивність: hover — показує кількість статей і приклади; клік — фільтрує пов'язані теми

## Результат

- `../data/processed/knowledge_map.html` — фінальна інтерактивна карта
