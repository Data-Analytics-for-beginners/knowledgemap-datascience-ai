# notebooks/

Jupyter notebooks для дослідження та прототипування.

## Призначення

Простір для швидкого дослідницького аналізу (EDA), перевірки гіпотез та прототипування коду перед перенесенням у продакшн-скрипти (`scraping/`, `analysis/`, `viz/`).

## Рекомендована практика

- `01_scraping_exploration.ipynb` — перевірка структури HTML сторінок блогу, тестування селекторів
- `02_data_eda.ipynb` — дослідницький аналіз зібраних даних (розподіл тегів, дат публікації тощо)
- `03_topic_modeling_prototype.ipynb` — підбір параметрів LDA, візуальна перевірка якості тем
- `04_graph_prototype.ipynb` — прототипування структури графа перед фінальною візуалізацією

**Правило:** фінальний, перевірений код переносити з notebooks у відповідні `.py`-модулі. Notebooks — для дослідження, а не для production-коду.
