# analysis/

NLP-аналіз тем на основі зібраних статей.

## Призначення

Виявити приховані теми та зв'язки між ними на основі заголовків, тегів та описів статей.

## Планована структура

- `text_preprocessing.py` — токенізація, стоп-слова, лематизація
- `topic_modeling.py` — TF-IDF + LDA (gensim) для виявлення тем
- `tag_network.py` — побудова матриці спільної появи тегів (co-occurrence) для графа

## Методологія (орієнтовний план)

1. Попередня обробка тексту (заголовки + excerpt)
2. Векторизація (TF-IDF)
3. Тематичне моделювання (LDA), підбір оптимальної кількості тем
4. Інтерпретація тем — присвоєння змістовних назв кластерам
5. Побудова матриці зв'язків: які теми/теги часто зустрічаються разом

## Результат

- `../data/processed/topics.json` — виявлені теми з ключовими словами
- `../data/processed/tag_cooccurrence.csv` — матриця зв'язків для побудови графа
