# scraping/

Скрипти для збору даних з блогу DataCamp.

## Призначення

Зібрати метадані статей блогу: заголовок, дату публікації, автора, теги/категорії, короткий опис (excerpt), URL.

## Планована структура

- `fetch_articles.py` — основний скрипт обходу блогу (пагінація, збір посилань на статті)
- `parse_article.py` — парсинг окремої сторінки статті (BeautifulSoup)
- `config.py` — базовий URL, затримка між запитами, User-Agent

## Правила

- Обов'язкова затримка між запитами (`time.sleep(1-2)`), щоб не перевантажувати сервер
- Перевірити `robots.txt` сайту перед масовим збором
- Результат зберігати в `../data/raw/articles_raw.csv` або `.json`
- Не комітити сирі HTML-сторінки

## Очікувані колонки результату

| Колонка | Опис |
|---|---|
| `title` | Заголовок статті |
| `url` | Посилання на статтю |
| `published_date` | Дата публікації |
| `author` | Автор (якщо доступно) |
| `tags` | Список тегів/категорій |
| `excerpt` | Короткий опис/перші речення статті |
