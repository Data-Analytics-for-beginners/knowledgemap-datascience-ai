
# 📊 Карта знань Data Science/AI на основі блогу DataCamp

## 🎯 Опис проекту

### **Назва проекту**

Аналіз та візуалізація ландшафту технологій Data Science/AI: дослідження тем блогу DataCamp

### **Мета**
Продемонструвати повний цикл аналітичного проекту від збору даних до презентації інсайтів, створивши інтерактивну карту знань з технологій Data Science та AI на основі контенту DataCamp блогу.

### **Цільова аудиторія**
Початківці в Data Science, які хочують зрозуміти:
- Які теми актуальні в галузі?
- Як технології пов'язані між собою?
- З чого почати навчання?
- Які навички в тренді?

###  Цінність для студентів**
- Розуміння структури галузі Data Science/AI
- Побудова персональної дорожньої карти для навчання
- Актуальні тренди та топ-теми
