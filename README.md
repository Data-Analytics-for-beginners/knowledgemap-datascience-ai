# 📊 Карта знань Data Science/AI на основі блогу DataCamp

## 🎯 Опис проєкту

**Назва проєкту:** Аналіз та візуалізація ландшафту технологій Data Science/AI: дослідження тем блогу DataCamp

**Мета:** продемонструвати повний цикл аналітичного проєкту від збору даних до презентації інсайтів, створивши інтерактивну карту знань з технологій Data Science та AI на основі контенту блогу DataCamp.

**Цільова аудиторія:** початківці в Data Science, які хочуть зрозуміти:
- Які теми актуальні в галузі?
- Як технології пов'язані між собою?
- З чого почати навчання?
- Які навички в тренді?

**Цінність для студентів:**
- Розуміння структури галузі Data Science/AI
- Побудова персональної дорожньої карти для навчання
- Актуальні тренди та топ-теми

## 🗂️ Структура репозиторію

```
knowledgemap-datascience-ai/
├── scraping/           # Скрипти збору даних з блогу DataCamp
├── data/
│   ├── raw/            # Сирі, необроблені дані (не комітити файли >10MB)
│   └── processed/      # Очищені, готові до аналізу дані
├── analysis/           # NLP-аналіз тем (тематичне моделювання, NER, кластеризація)
├── viz/                # Побудова інтерактивної карти знань (граф)
├── notebooks/          # Jupyter notebooks з дослідженням (EDA, прототипування)
├── .github/workflows/  # CI/CD та Claude Code GitHub Action
├── CLAUDE.md            # Інструкції для Claude Code на цьому репозиторії
├── requirements.txt     # Python-залежності
└── README.md
```

## 🛠️ Технологічний стек

- **Python 3.11+**
- **Збір даних:** requests, BeautifulSoup4
- **Обробка даних:** pandas
- **NLP:** scikit-learn (TF-IDF), gensim (LDA), spaCy / NLTK
- **Граф-аналіз:** networkx
- **Візуалізація:** pyvis, plotly, matplotlib/seaborn
- **(опційно) Веб-інтерфейс:** Streamlit

## ⚙️ Встановлення та запуск

```bash
# Клонування репозиторію
git clone https://github.com/Data-Analytics-for-beginners/knowledgemap-datascience-ai.git
cd knowledgemap-datascience-ai

# Створення віртуального середовища
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Встановлення залежностей
pip install -r requirements.txt
```

Далі — послідовно запускати скрипти з `scraping/`, `analysis/`, `viz/` (детальні інструкції з'являться в кожній підпапці по мірі розробки).
